# Shukla Chaat House — Website

A one-page website for Shukla Chaat House, a legendary chaat shop in Hazratganj, Lucknow, serving Aloo Tikki Chaat, Matar Chaat, Pani ke Batashe, Dahi Bada and Papdi Chaat since 1968.

- Address: Shop No. 1, Church Building, 11 Shahnajaf Road, Hazratganj, Lucknow 226001
- Phone: +91 98390 42164
- Hours: Daily 3:00 PM – 11:00 PM

Built as a single static `index.html` (Tailwind via CDN). Details are taken from public listings (Justdial, Tripadvisor, Wanderlog) and can be updated by the owner at any time.
